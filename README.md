# Painel de Recados

Pequeno sistema de controle de mensagens feito com React + Vite.

## Como rodar no VS Code
1. Abra a pasta no VS Code (`File > Open Folder`).
2. Abra o terminal (`Ctrl + '`) e rode:
   ```
   npm install
   npm run dev
   ```
3. Acesse o endereço mostrado (normalmente http://localhost:5173).

## Funcionalidades
- Input controlado
- Botão de adicionar (ou tecla Enter)
- Lista de mensagens
- Botão de remover
- Botão Importante / Desmarcar (destaca o recado)
- Mensagem quando a lista estiver vazia
